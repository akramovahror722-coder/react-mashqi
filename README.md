# React Mashqi

Komponentlar, props, state va hookslarni jonli misollarda o'rganish uchun interaktiv loyiha.

## Imkoniyatlar

- **State** — `useState` bilan hisoblagich, qadam va panelni boshqarish
- **Props** — bitta komponentni turli props bilan qayta chizish
- **Effects** — `useEffect` bilan jonli soat, sahifa sarlavhasi va oyna o'lchami
- **Kompozitsiya** — `map`, `filter` va kichik komponentlar bilan vazifalar ro'yxati
- Har bir demo uchun jonli kod ko'rinishi
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

React · Vite · JavaScript · Hooks · Components · CSS

## Ishga tushirish

```bash
npm install
npm run dev
```
